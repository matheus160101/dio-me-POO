# Desafio de Modelagem e Diagramação - iPhone

## Descrição
Este repositório contém a modelagem e implementação de um componente iPhone, com funcionalidades como Reprodutor Musical, Aparelho Telefônico e Navegador na Internet.

## Diagrama UML
O diagrama UML das classes e interfaces foi criado para representar as funcionalidades descritas.

![Diagrama UML do iPhone](Diagrama_UML.png)

## Implementação

As interfaces e a classe `iPhone` foram implementadas conforme a modelagem.

- **ReprodutorMusical**: Interface para controlar a música.
- **AparelhoTelefonico**: Interface para controlar chamadas telefônicas.
- **NavegadorInternet**: Interface para controlar a navegação na internet.
- **iPhone**: Classe que implementa as três interfaces.

### Como rodar:

Clone o repositório e compile os arquivos `.java` para testar a funcionalidade do iPhone.
